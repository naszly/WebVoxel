# WebVoxel

WebVoxel is a real-time interactive voxel rendering project built with WebGPU.
It is designed to run on both native platforms and the web.

It is the implementation of my BSc computer science engineering thesis, *Real-time interactive voxel rendering using WebGPU*.

Source available for reference. All rights reserved unless stated otherwise.

## Setup

See [`setup.md`](setup.md) for build instructions.

## Key features

- Real-time voxel rendering
- Chunk-based world management
- Interactive editing
- Native and web builds

## Technologies

- C++
- WebGPU
- Dawn
- Emscripten / WebAssembly
- CMake
- GLFW
- ImGui
- GLM
- spdlog
